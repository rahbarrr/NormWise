# NormWise: 60-Second Technical Pitch

> *"Technically, NormWise is a decoupled three-tier system unified on PostgreSQL 16 to avoid the operational fragilities of polyglot database clusters.*  
>  
> *The frontend is built on React 19, Vite, and Tailwind CSS, interfacing over REST APIs with a Node.js 20 Express service utilizing Prisma ORM.*  
>  
> *When a specification is received, we execute deterministic attribute extraction, decomposing the text into engineering parameters. Candidate retrieval is tri-engine: filtering structured relational columns, executing PostgreSQL tsvector full-text search, and querying 1536-dimensional dense embeddings via pgvector HNSW cosine similarity—achieving 88.9% Recall@1.*  
>  
> *Crucially, retrieval is decoupled from validation: our currentness engine independently checks publication years and supersession trees; a recursive CTE knowledge graph discovers allied standards up to depth 3 without needing Neo4j; a deterministic rule engine maps official DPIIT Quality Control Orders; and our evidence engine links verbatim clause snippets.*  
>  
> *Finally, server-side RBAC enforces separation of duties—preventing officer self-approval—and records all actions in an append-only audit trail with SHA-256 integrity hashes."*
